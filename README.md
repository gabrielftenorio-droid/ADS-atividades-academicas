# Atividades Acadêmicas — Análise e Desenvolvimento de Sistemas

Este repositório reúne atividades práticas e projetos selecionados que desenvolvi durante minha graduação em **Análise e Desenvolvimento de Sistemas**.

A organização por áreas foi criada para registrar minha evolução ao longo do curso e facilitar a consulta aos diferentes conteúdos que venho estudando, desde programação e banco de dados até modelagem de sistemas, computação em nuvem e desenvolvimento web.

Os projetos foram mantidos próximos das versões desenvolvidas nas disciplinas. Quando necessário, foram realizados apenas ajustes para organização, execução ou documentação no GitHub.

#### Consulta de Signos com PHP e XML

Aplicação desenvolvida para identificar o signo correspondente à data de nascimento informada pelo usuário.

O projeto utiliza formulário HTML, processamento com PHP, dados armazenados em XML e uma interface construída com Bootstrap e CSS.

Durante a implementação também foi necessário trabalhar com comparação de datas e tratar o intervalo de Capricórnio, que atravessa a mudança entre dezembro e janeiro.

**Tecnologias utilizadas:** HTML, PHP, XML, CSS, Bootstrap e XAMPP.

📁 `desenvolvimento-web/01-consulta-signos-php`

## Objetivo do repositório

Além de armazenar atividades da faculdade, este repositório funciona como um registro da minha evolução durante a graduação.

A proposta não é transformar todas as atividades acadêmicas em projetos independentes, mas selecionar e organizar trabalhos que representem os conhecimentos praticados em cada etapa do curso.

Projetos que recebem uma evolução maior podem ser desenvolvidos posteriormente em repositórios próprios.
