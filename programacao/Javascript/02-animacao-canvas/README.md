# Desenvolvimento em JavaScript – Canvas

## Sobre o projeto

Este projeto foi desenvolvido como parte das atividades acadêmicas do curso Superior de Tecnologia em Análise e Desenvolvimento de Sistemas (ADS).

A atividade teve como objetivo aplicar conceitos de JavaScript e manipulação gráfica por meio da API Canvas, desenvolvendo uma animação interativa executada diretamente no navegador.

## Funcionalidades implementadas

- Criação e desenho de partículas utilizando Canvas 2D.
- Movimentação contínua dos elementos gráficos.
- Detecção de colisões com os limites da área de desenho.
- Alteração gradual das cores.
- Interação com o mouse para modificar a cor das partículas.
- Atualização da animação utilizando `requestAnimationFrame()`.

## Tecnologias e recursos

- HTML5
- JavaScript
- Canvas API
- Visual Studio Code
- Live Server

## Estrutura do repositório

- `Projeto/`: arquivos HTML e JavaScript da aplicação.
- `Relatorio/`: relatório acadêmico da atividade.
- `assets/evidencias/`: capturas de tela do desenvolvimento e dos testes.

## Objetivo acadêmico

Aplicar conhecimentos de programação JavaScript, manipulação de elementos gráficos, funções, objetos, eventos e estruturas de repetição, documentando o processo de desenvolvimento e os resultados obtidos.
