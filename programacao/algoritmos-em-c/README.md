# Algoritmos e Programação Estruturada em C

Este diretório reúne atividades práticas desenvolvidas durante a disciplina de **Algoritmos e Programação Estruturada**, no curso de Análise e Desenvolvimento de Sistemas.

As atividades registram meu primeiro contato acadêmico com a linguagem C e a evolução na aplicação de conceitos fundamentais de programação estruturada.

## Conteúdos praticados

- Operadores aritméticos, relacionais e lógicos
- Estruturas condicionais
- Estruturas de repetição
- Vetores
- Funções
- Entrada e saída de dados
- Organização e decomposição de problemas

## Atividades

| # | Atividade | Principais conceitos |
|---|---|---|
| 01 | Operadores e condicionais | Operadores, expressões e estruturas condicionais |
| 02 | Estruturas de repetição | Laços de repetição e controle de fluxo |
| 03 | Vetores | Arrays, armazenamento e processamento de dados |
| 04 | Funções | Modularização, parâmetros e retorno de valores |

> Estas atividades foram desenvolvidas como parte da minha formação acadêmica e são mantidas neste repositório como registro da evolução dos meus estudos em programação.
